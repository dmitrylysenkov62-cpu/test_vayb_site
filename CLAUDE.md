## Среда работы

## Структура заказов

Все заказы хранятся в папке `orders/`. Каждый заказ — отдельная подпапка с коротким латинским именем по нише (например `repetitor-math/`). Реестр всех заказов — `orders/_index.md`.

**Как работать с заказами:**
- Разбор ТЗ (скилл `razbor-tz`) → создаёт `brief.md` **внутри `orders/<имя>/`**, добавляет строку в `orders/_index.md`
- Сборка сайта (скилл `vibe-sait`) → читает `brief.md` из `orders/<имя>/`, кладёт `index.html` и файлы **туда же**
- Статус в реестре: `бриф` → `в работе` → `готово`

Когда пользователь говорит «ты делал ТЗ для [описание]» — читай `orders/_index.md`, находи нужную строку, смотри папку.

## Поиск и исследование

- **Анализ сайтов конкурентов и рынка** — всегда использовать Tavily (ключ в `.env` → `TAVILY_API_KEY`).
- **Всё остальное** — встроенный поиск Claude.
